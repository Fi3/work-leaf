## Correction and validation

`audit_title_delivery.py` hashes and compiles the exact admitted auditor bytes with
two unique private source substitutions: remember whether a request is the thread's
first, and permit that already-owned first title request. All subsequent ownership,
ordered occurrence, typed acceptance, exact public delivery, factor-span, source,
terminal outcome and endpoint-hash gates remain the admitted code. Exact compilation
does not use a cached Python import. The derivative and executed derived-code hashes
are reported separately; the input still pins the original admitted helper.

RED was observed with the original auditor on a full title policy followed by two
raw title requests. The corrected suite runs with
`python3 -B -m unittest test_title_delivery.py` from this directory: five tests pass.
It retains the original failure, rejects untraced policy/wrong role/unsupported later
title requests, checks no-title output identity, and exercises the complete source
wrapper with unchanged nonzero terminal status, hashes and create-new behavior.
