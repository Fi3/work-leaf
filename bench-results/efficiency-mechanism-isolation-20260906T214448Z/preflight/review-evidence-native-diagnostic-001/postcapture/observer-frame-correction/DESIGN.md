# Source-bound observer metadata frame derivative

This postcapture derivative qualifies only the documented observer metadata additions. The admitted collector (`d3fd8c80746bf4bce565cb5f0a2e2eab29681b3aa40f89196cf95ebf344ed9ee`), primitive (`34a34276e2f3914b35c72521a303c2cb41ec54c646299cda2b7a9c600146a257`), raw captures, failed exit 101 and original `REVIEW-EVIDENCE-SOURCE-AUDIT.json` remain unchanged.

The derivative compiles those exact bytes without cached imports. Only `join_review_inputs`' whole-frame equality predicate delegates to a privately held proof. All original archive, owned prompt, accepted/public/native input, native tool/output, source and terminal gates continue through the original collector. The capture arrays are not rewritten or filtered. A changed proof input cannot activate the predicate.

The proof first binds the original input manifest, collector/primitive, current derivative, observer config and exact observer executable SHA (`238bdc610a28edd328d91046f9674dbe59ad2f2d7520fedf681c1ae95a56e386`). Capture paths must be canonical children of the configured observation root. Primary app-server start/end metadata must opt into raw response capture and bind original/forwarded/server/settings/journal bytes. Every rewrite journal entry must match its physical original/forwarded frame bytes, hashes, lengths, typed RPC ID, method and changed flag; missing, duplicate or extra entries fail.

The typed comparator permits only:

- `initialize.params.capabilities.optOutNotificationMethods`: append `rawResponseItem/completed` once if absent. Existing `experimentalApi` must already be the Boolean `true`; it cannot be enabled by this derivative. Every other capability and existing notification remains identical.
- `thread/start.params.experimentalRawEvents`: the documented Boolean `true` value.

Every other frame, including every `turn/start` and interrupt, is byte-identical and ordered. Every unchanged metadata frame is byte-identical too. Boolean/numeric RPC aliases and unbound permission markers fail. The proof exports no prompt/archive/tool-output bodies, only locators and digests. The derived report has a distinct schema/provenance section and create-new path; it cannot overwrite the original failure or imply full scripted diagnostic success, accounting completeness, quality, or a causal effect.

Tests precede implementation. Synthetic cases cover both permitted additions, already-correct identity, prompt/ID/order mutation, extra capabilities/notifications, malformed IDs, journal omissions/duplicates/hash mismatches, raw settings drift and pre-existing `experimentalApi=false`. The original actual diagnostic failure is already retained. An actual source-bound replay must verify all three accepted inputs and the single complete archive read while retaining terminal exit 101. Source hashing and frame/journal iteration are linear in input bytes and records; the original collector's explicitly documented partial-read O(R × B) primitive remains unchanged.
