# Completed global-hunk pilot: public/host mechanism screen

## Result and scope

The sole completed non-Work-Leaf pilot exhibits the proposed joint work pattern:
publish a buildable implementation together with feature tests, receive an actual
host acceptance/commit receipt, run a focused validation, then return DONE.
All three initial authors exhibit this sequence, with one accepted edit each.
This is an observed change in the unit and timing of work, not an explanation
that merely renames fewer responses.

The exact corrected parser is activated on a current-run accepted proposal:
the old frozen host rejects that proposal solely at a unique old block behind
its forward cursor; the corrected host plans all five files. This is a concrete
mechanism witness, not a modeled token saving or a replayed alternative workflow.

The full observed raw cost is 18,545,304. Parent reports an independent native
join of all 31 completed public turns, 191 responses, zero compaction and
1,220,632 uncached-plus-output tokens; that separate accounting/custody artifact
is authoritative for native qualification. The run completes in 58m24.72s.
The numerical observation is 48.6513% below historical Direct mean
36,116,381 2/3 and falls within the historical WL conditional recorded range
17,471,532–19,725,532. It is one complete package observation, not a replicated
effect estimate or identification of a unique historical causal fraction.

Important non-target distinction: no inspected prompt or feedback removes a
required feature or asks the author to cut task scope. Implementations, feature
tests, real reviews, repairs and integration remain. Nevertheless, the exact
final specimen fails the frozen completion feature check at line 23, missing the
question with a reviewer selected. Visual and status checks pass. The user's
no-quality-loss working assumption is not evidence that this failed check passed,
nor does this one failure establish treatment-induced scope removal. Quality
equivalence is not independently verified by this screen.

Investigation was limited to completed public agent streams, owned finals, host
events/command receipts, observer metadata and already-qualified historical
sources. No private reasoning was inspected; no provider, workflow, candidate
test or source modification was performed. Only these evidence reports are
written. No additional experiment is selected.

## Bounded decision

The evidence supports an upstream explanation more concrete than "fewer
responses": the joint contract changes the submitted unit to implementation
plus tests; a functioning host publication boundary commits that unit and
returns real state; focused-check handoff is then followed in practice.
The accepted current proposal replay verifies a source-level obstruction to
that unit was actually removed. Reviews/fixes/integration remain real and
priced. This standalone, provider-backed full execution reproduces the
historical whole-cost magnitude.

This establishes a reproducible non-WL operational mechanism and one complete
observed magnitude, not unique attribution of the historical gap. Individual
additive percentages are not required to explain a joint cause; they simply
are not identified here. The concrete remaining acceptance question is whether
the exact final completion failure is compatible with the required quality
non-target qualification, not whether another generic cost screen should run.
No treatment-induced deletion of required scope is demonstrated. Nor is
verified quality-equivalent completion demonstrated. G01/G02/G03 decisions
must retain that distinction and the independently qualified native accounting.
