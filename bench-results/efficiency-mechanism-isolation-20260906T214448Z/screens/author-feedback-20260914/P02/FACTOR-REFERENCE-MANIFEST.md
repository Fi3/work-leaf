benchmark preparation, not a new bypass or a modified host check.

native launch. The private startup catalog view is not a token-saving factor;
it restores the reference input. P02/catalog_dispatch.py recognizes the actual
`exec --color never resume` order and bypasses that view on resumed sessions.
BUG003's seven fail-first tests establish command classification. Actual fresh
and resumed input fidelity must also be checked in P03/P04, using existing native
receipts, without another setup diagnostic. The reference's later developer
catalog omits two plugin descriptions; it must not be silently reinjected.

namespace and provider randomness are explicit observation differences. They

Unexpected non-target source/input drift invalidates attribution and retains all

differences must be checked, not dismissed merely because total instructions match.
