# Withdrawn Seven-Cell Allocation

No exact seven-cell allocation is supported. Every Work Leaf token total can omit interrupted
directive responses, so equations built from those totals do not measure normal Work Leaf token use.

The condition definitions and preserved artifacts remain available for designing a later study after
a valid interrupted-response measurement contract is frozen. See
`../efficiency-point7-exact-accounting-20260828T113610Z/FINAL-RESULT.md`.
